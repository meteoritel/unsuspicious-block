# Unsuspicious Block

> 面向 Minecraft 1.21.1 的考古探索与发现记录模组。
>
> 本页和本 Wiki 以正式版本 `1.5.2` 为准。

## 这个模组做什么

Unsuspicious Block 为 Minecraft 的考古内容增加了更完整的探索工具和记录方式。你可以扫描可疑方块、快速取出已经确认的战利品，并在考古笔记中整理发现过的战利品表、物品、条件和位置。

## 主要内容

- **考古笔记**：一本记录战利品发现地点和探索过程的笔记。
- **可疑解析仪**：扫描范围内是否存在可疑方块或战利品箱。
- **考古铲**：快速清理沙子/沙砾以挖出可疑方块。
- **失落书页与附魔**：通过考古发现获得四种面向探索和收集的附魔。
- **猫之瞳**：查看附魔台、铁砧和砂轮中原本隐藏的信息。
- **标本箱**：携带五格物品，并让箱内部分物品保持随身生效。
- **纹饰陶轮台**：复制纹饰陶片、制作纹饰陶罐，并支持漏斗自动化。
- **不可疑方块**：把物品封存在伪装成可疑方块的沙子或沙砾中。
