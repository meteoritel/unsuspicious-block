# Unsuspicious Block

> 面向 Minecraft 1.21.1 的考古探索与发现记录模组。
>
> 本 Wiki 以 `1.6.0` 版本为基准，面向游玩本模组的玩家编写。

## 这个模组能做什么

Unsuspicious Block 围绕原版考古、遗迹探索与战利品收集构建了一套完整的工具与记录系统：你可以先扫描可疑方块再决定如何发掘，在考古笔记中模拟不同条件下的掉落概率并记录每次发现，还能通过淘盘、制陶、远古植物和结构回溯进一步利用考古收获。

## 玩法一览

- **[考古笔记](zh-Archaeology-Journal)**：按分类收录战利品表、模拟不同条件与幸运下的掉落概率，并记录发掘坐标与日志。
- **[可疑解析仪与考古铲](zh-Reader-and-Shovel)**：扫描并高亮可疑方块与未开容器、直接在画面显示目标详情，再一键取出战利品或连挖清沙。
- **[失落书页与附魔](zh-Lost-Pages-and-Enchantments)**：将考古发现的失落书页锻造为附魔书，获取四种面向打捞、剪毛、刷拭和化石采集的附魔。
- **[钓鱼打捞与淘盘淘洗](zh-Fishing-and-Panning)**：在开阔水域打捞沉船物资，或用铜、金、黑曜石淘盘在河流和下界岩浆中淘洗矿砂与遗物。
- **[猫之瞳](zh-Eye-of-Cat)**：随身携带即可在附魔台、铁砧和砂轮中查看完整候选附魔、成本分解与返还预览。
- **[标本箱](zh-Specimen-Box)**：五格便携容器，放进去的随身功能物品、兼容饰品与不死图腾依然生效。
- **[纹饰陶轮台](zh-Pottery-Wheel)**：复制纹饰陶片、拼制四面纹饰陶罐，支持预览灯箱与漏斗自动化。
- **[不可疑方块](zh-Unsuspicious-Blocks)**：把任意物品封存进外观与可疑方块一致的沙子或沙砾中。
- **[咕噜荆芥](zh-Purrmint)**：由嗅探兽发掘或河流淘洗获得的远古植物，成熟植株与盆栽可穿墙驱避苦力怕与幻翼。
- **[花火粉与回溯粉](zh-Spark-and-Rewind-Dust)**：把火把花磨成燃料粉末，或合成回溯粉让世界生成的结构在原址重新生成。
