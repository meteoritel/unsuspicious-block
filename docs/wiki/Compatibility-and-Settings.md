# 联动与服务器设置

本页只介绍玩家在安装其他 Mod 或进入多人服务器时需要知道的行为。所有联动都是可选的。

## 配方查看器

- JEI 提供本模组配方和纹饰陶轮台专用配方分类。
- REI 和 EMI 可以查看普通配方。

## Jade

安装 Jade 后，已经被当前玩家解析过的可疑方块可以在方块信息中显示解析出的战利品。未解析的方块不会因为 Jade 直接泄露内容。

## 饰品栏

安装 Trinkets（Fabric）或 Curios（NeoForge）后，考古笔记、猫之瞳和标本箱可以装备到对应饰品栏。标本箱内部的可携带物品也会继续参与本模组的携带检测。

## Artifacts

安装 Artifacts 后，标本箱可以代理兼容饰品的装备效果。具体可代理的饰品取决于 Artifacts 当前版本和该饰品自身的实现。

## Lootr

NeoForge 提供可选 Lootr 兼容，不同玩家开启同一个 Lootr 战利品箱内容会互相独立记录。

## 服务器设置

战利品追踪设置按世界保存，切换存档时不会沿用另一张存档的规则。服务器管理员可以调整：

- 需要收录到考古笔记的战利品表匹配规则
- 每张战利品表的日志保留上限，默认 512 条，可调整范围为 64–4096 条
- 战利品容器追踪超时，默认 6000 游戏刻，也就是 5 分钟

这些设置影响日志和目录的收录范围，不会改变解析仪的扫描半径或四种附魔的固定效果。

## 多人游戏注意事项

客户端和服务端都需要安装本模组。考古目录由服务器提供，个人的解锁进度和日志不会自动在不同服务器之间共享。
