# 常见问题

## 可以把本模组加入已经玩了一半的存档吗？

可以。

- 河流中的「闪烁的光」会在玩家附近的河流群系自然生成，无需跑去未探索的新区块。
- 永久世界生成点（「闪烁的光」与下界的「幽微的光」）会在你新探索的区块中生成。
- 尚未被打开过的遗迹箱子和尚未生成战利品的可疑方块，之后探索时依然有机会获得本模组物品。如果你想让已经搜刮过的原版或模组结构重新生成一次，可以使用[回溯粉](zh-Spark-and-Rewind-Dust)。

## 为什么考古铲左键敲不动可疑方块？

这是刻意的防误操作保护：普通左键敲击可疑方块不会完成破坏，也不会向下连挖。如果你确实想挖掉它，请**按住潜行键**再挖掘；或者先用可疑解析仪扫描，再用考古铲**右键**直接取出战利品。

## 为什么朋友用解析仪扫过方块，我用考古铲还是取不出东西？

可疑方块的扫描权限与发掘记录按玩家独立绑定。每位玩家都需要用自己的可疑解析仪扫描过该方块后，才能用考古铲直接取物。

## 为什么考古笔记里有些物品显示 `?` 或「需要条件」？

- **`?`（尚未计算）**：进入世界后，笔记会先展示目录和物品列表，并在后台分批模拟概率。正在浏览的表会优先计算，稍等片刻即可刷新出数值。
- **`需要条件` / `未命中`**：说明该物品依赖特定的环境条件（如群系、开阔水域、天气）、工具附魔或更高的幸运值。你可以打开网格顶部的**场景**栏勾选条件、调整装备参数后点击**计算**，或者直接对已发现物品使用**推荐配置**。

## 模组主要特殊物品从哪里获得？

| 物品 | 获取途径 |
|---|---|
| **古代金币** | 古迹废墟普通可疑方块（5%）、河流淘洗、考古铲挖沙/砂砾（0.3%）、化石猎手掉落、100% 完成任意笔记战利品表 |
| **失落书页** | 古迹废墟稀有可疑方块（8%）、河流淘洗、化石猎手掉落 |
| **猫之瞳** | 埋藏的宝藏宝箱（100% 生成 1 个） |
| **标本箱** | 村庄武器匠房屋箱子（30% 概率） |
| **咕噜荆芥种子** | 嗅探兽挖掘远古种子时额外 50% 概率带出 |

## 回溯粉会不会误伤我的基地？

**会。** 回溯粉是在原位重新运行结构生成，而不是“恢复某个时间点的存档备份”。它会覆盖结构包围盒内玩家自己建造或改造的方块，请不要在改造成基地或存放重要物资的结构内使用。

请在 [GitHub Issues](https://github.com/meteoritel/unsuspicious-block/issues) 提交问题，并附上：

- Minecraft 版本、加载器（Fabric / NeoForge）及版本、Unsuspicious Block 版本
- 相关联动模组列表（如 JEI、Jade、Create、Mekanism、Lootr 等）
- 详细复现步骤与崩溃日志（如有）
- 多人游戏问题请说明发生在客户端还是服务端
