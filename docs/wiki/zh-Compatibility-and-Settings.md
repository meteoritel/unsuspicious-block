# 联动与设置

本页汇总 Unsuspicious Block `1.6.0` 的可选模组联动、默认按键绑定，以及单人/服务器可调整的设置项。

## 可选模组联动

### 配方查看器

- **JEI**：展示本模组全部合成配方、纹饰陶轮台专用配方分类，以及未烧制陶罐/陶片的熔炉烧制配方；在考古笔记中悬停已解锁物品按 `U` / `R` 可直接查询用途与配方，在背包或 JEI 列表悬停物品按 `C` 可在笔记中检索。
- **REI / EMI**：可查看常规合成与熔炼配方。

### Jade

安装 **Jade** 后，对准以下目标可直接在画面顶部查看额外信息：

- **可疑方块**：显示你已经用可疑解析仪扫描过的内部战利品（未扫描方块不会剧透）。
- **不可疑方块**：显示封存的物品与封存玩家。
- **淘洗点**：显示「临时/永久」类型与剩余可用次数；服务端同样安装 Jade 时，还会显示临时点的消失倒计时或永久点的下次恢复倒计时。

### 饰品栏与 Artifacts

- **Trinkets**（Fabric）或 **Curios**（NeoForge）：为[考古笔记](zh-Archaeology-Journal)与[标本箱](zh-Specimen-Box)提供饰品槽，为[猫之瞳](zh-Eye-of-Cat)提供护符（Charm）槽。
- **Artifacts**：兼容的 Artifacts 饰品放入随身携带的[标本箱](zh-Specimen-Box)后，依然保留装备效果。

### 制陶联动（仅 NeoForge）

- **Mekanism**（`10.7.19+`，已在 `10.7.19.85` 验证）：可使用**电力熔炼炉**烧制未烧制的纹饰陶片与陶罐，成品保留原纹饰。
- **Create**（`6.0.10`）：可使用**鼓风机**进行批量熔炼烧制未烧制的纹饰陶片与陶罐，成品保留原纹饰。

### Relics

安装 **Relics** 时，在开阔水域使用「泥底打捞」附魔钓鱼有 2% 概率额外带出其饰品；此外该模组的 `relics:data` 组件默认排除在考古笔记签名之外，避免同一饰品因随机属性刷屏成多条重复记录。

### Lootr（仅 NeoForge）

- 每名玩家的考古笔记独立记录自己取出的战利品。
- 开启队伍共享库存时，队友共享容器战利品，领取记录仍各自归属本人。
- 考古铲只能提取你扫描时绑定的那份库存；Lootr 重新生成库存后需要再次扫描。

## 默认按键绑定

可以在游戏内 **选项 → 控制 → 按键绑定** 的 `Unsuspicious Block` 分类中修改：

| 按键 | 功能 |
|---|---|
| `C` | 打开携带的考古笔记；或在背包/JEI 悬停物品上发起检索 |
| `V` | 切换可疑解析仪的扫描等级（单方块 / 3×3×3 / 5×5×5 / 7×7×7） |
| `H` | 显示或隐藏可疑解析仪的扫描 HUD 面板 |

## 游戏内配置与文件位置

### 1. 世界战利品追踪规则

保存在 `<存档目录>/serverconfig/unsuspiciousblock-loot-tracking.json`（Fabric 与 NeoForge 共用）。

- **修改入口**：在考古笔记左侧「战利品表管理」点击「世界规则」，或通过 Fabric ModMenu / NeoForge 模组配置界面进入。多人服务器与局域网共享需要 OP 权限等级 2，单人房主可直接编辑。
- **可调内容**：
  - 开关内置追踪规则、添加额外前缀/精确表规则、排除指定根表
  - 每张表日志保留上限：默认 `512` 条（可设 `64–4096`）
  - 战利品容器追踪超时：默认 `6000` 游戏刻（5 分钟，可设 `600–60000`）
  - 签名排除组件列表（默认包含 `relics:data`）
- 也可以直接编辑该 JSON 文件并在游戏内执行 `/reload` 立即重载。

### 2. 补充表名（整合包/服务器通用）

管理员在「战利品表管理 → 管理表名」编辑或导入的自定义表名，按语言保存在 `config/unsuspiciousblock/loot_table_lang/<语言代码>.json`，由同一服务端实例下的所有世界共用。

### 3. 淘盘与淘洗点设置

- **Fabric**：全局文件 `config/unsuspiciousblock/panning.json`。
- **NeoForge**：随存档保存于 `<存档目录>/serverconfig/unsuspiciousblock-panning-server.toml`（单人模式下可在 NeoForge 模组配置界面修改）。
- **主要参数与默认值**：
  - 自然点尝试间隔：`600` 刻（30 秒），每维度上限：`5` 个，最小间距：`32` 格
  - 自然点寿命：`24000–48000` 刻（20–40 分钟），采空区域冷却：`36000` 刻（30 分钟）
  - 单次淘洗时长：`100` 刻（5 秒），每个点可用次数：`3` 次
  - 金淘盘幸运加成：`+1.0`，金淘盘再生概率：`0.10`（10%），黑曜石淘盘水中幸运惩罚：`1.0`

## 多人游戏注意事项

客户端和服务端必须安装相同版本的本模组。考古目录与世界规则由服务端统一提供，玩家的解锁进度和发掘日志保存在各自的服务端玩家数据中，不会跨不同服务器自动同步。
