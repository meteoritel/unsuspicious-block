# 考古笔记

考古笔记记录你已经获得的战利品，同时帮你查清尚未到手的物品来自哪张战利品表、需要什么条件、大致有多大概率掉落。

## 制作与打开

在工作台中将 **1 本书** 和 **1 把刷子** 合成考古笔记。

![一本书和一把刷子合成考古笔记](https://raw.githubusercontent.com/meteoritel/unsuspicious-block/1.21.1/docs/image/wiki/zh-recipe-archaeology-journal.png)

- 手持笔记右键打开。
- 将笔记放在背包、饰品栏（安装 Trinkets / Curios 时）或[标本箱](zh-Specimen-Box)中，按默认键 `C` 即可打开。
- 在背包或 JEI 界面将鼠标悬停在任意物品上并按 `C`，会自动以该物品注册名在笔记中发起检索；如果找到对应条目，会直接定位过去。
- 界面支持按 `Backspace` 或鼠标返回侧键逐级返回上一页，并按世界和玩家记住你上次的阅读位置。

## 首页与分类

打开笔记后的第一页右侧显示你的探索统计：刷拭次数、打开的战利品箱数、当前日志条数与已标注数量，以及最近一次记录的时间和最近发现的物品。

左侧目录首先载入七个分类与战利品表层级，随后在后台逐步补全各表的概率估算（优先计算你正在查看的表）：

- **刷扫发掘**：可疑方块战利品。
- **遗迹宝箱**：埋藏的宝藏、远古城市等遗迹容器。
- **钓鱼与打捞**：原版钓鱼与「泥底打捞」附魔掉落。
- **陶罐**：装饰陶罐战利品。
- **淘筛采集**：河流「闪烁的光」与下界「幽微的光」淘洗产出。
- **化石采集**：「化石猎手」附魔的额外化石掉落。
- **其他**：未归入上述分类的已追踪战利品表（例如自定义或联动表）。

## 目录、搜索与战利品网格

目录支持连续滚轮滚动、`WASD` / 方向键浏览、`Shift + 点击` 收藏条目、按默认/名称/解锁状态/物品数量/收藏/更新时间排序，以及「隐藏未解锁」开关。

### 搜索语法

| 输入格式 | 检索范围 |
|---|---|
| 直接输入文字 | 按战利品表名称搜索 |
| `@名称` | 按模组或命名空间搜索 |
| `%类型` | 按战利品表类型搜索 |
| `$名称` | 按物品名称搜索 |
| `$#名称` | 按物品标签搜索 |

### 物品格与剧透保护

- **尚未发现的物品**在网格中显示为未知图标（「待解析」），不会提前剧透物品名称、掉落率或具体获取条件。
- **已发现的物品**会并列展示**模拟掉落率**与表中声明的**触发率**，并标明是否受幸运影响以及附魔、耐久、数量区间等生成规则。
- 同一标签展开的物品会折叠为分组卡片；父表下属的具名子表会作为独立入口展示，点击即可进入子表。
- 安装 **JEI** 后，介绍页和物品格中的已解锁物品支持按 `U`（查用途）和 `R`（查配方），关闭 JEI 后自动回到笔记。

## 场景条件与概率模拟

许多战利品依赖特定群系、天气、开阔水域、工具附魔或幸运值。在物品网格顶部的**场景**栏中，你可以按实际探索装备模拟掉落概率：

- **选择环境条件**：点击场景下拉栏勾选需要同时满足的条件（如群系、下雨、开阔水域等）。
- **设置工具、附魔与幸运**：点击「参数…」调整手持工具、附魔等级与幸运值（`-5` 到 `10`），也可以点击 **同步自身** 一键读取你当前所处位置、天气、手持工具、附魔和幸运值。
- **按需计算**：点击 **计算** 后，服务端会对当前设定执行 `10,000` 次抽样模拟并缓存结果。
- **条件树与推荐配置**：展开「条件树」（可在放大灯箱中拖动和缩放查看）了解每条分支的满足状态；对已发现的物品或分支点击推荐，系统会直接给出满足获取条件的参数与环境调整方案。

## 日志与位置记录

「日志」页签记录实际发生的每次发现，包含物品与数量、坐标、维度、群系、结构来源、发现时间和详细出处。

- 可以按时间区间、维度、群系或备注状态分组浏览。
- 打开日志详情后，可以添加备注并一键复制 `/tp` 传送指令，方便之后回到原地。
- 支持单条删除、批量选择删除、清空当前表日志或清空全部日志（删除日志不会回退物品解锁进度与成就）。
- 每张表都可以单独设置自动保留上限或一键清理旧记录；**已备注的日志始终受到保护，不会被自动清理**。

## 什么会推进笔记进度？

以下行为会实际解锁条目并写入日志：

- 刷拭可疑方块（或用[考古铲](zh-Reader-and-Shovel)取出已扫描的战利品）
- 发掘装饰陶罐
- 钓鱼获得战利品
- 开启带战利品表的容器（含箱子矿车等实体容器）
- 用[淘盘](zh-Fishing-and-Panning)淘洗或使用[化石猎手](zh-Lost-Pages-and-Enchantments)采掘自然骨块

> [可疑解析仪](zh-Reader-and-Shovel)的扫描可以提前预览方块内有什么，但只有真正取出战利品后，日志和解锁进度才会结算。

当一张表及其包含的候选取物全部解锁至少一次时，完成度达到 100%，你会一次性获得 **1 枚古代金币** 奖励。

## 管理战利品表与世界规则

点击笔记左侧的「战利品表管理」侧签，可以查看当前世界收录的全部战利品表：

- 通过**全部 / 已追踪 / 未追踪 / 最近遇到**快速筛选，或搜索表名与完整 ID（`命名空间:路径`）。
- 界面会明确区分**目录顶层条目**（由收录规则直接纳入）与**由父表收录**的子表，并列出命中规则与父表引用。
- 拥有权限时（单人存档房主或服务器 OP 权限等级 2），可以在「世界规则」中开关内置规则、添加前缀/精确规则或排除单表；保存前会先预览新增、移除与位置变化。
- 管理员还可以编辑并导入多语言**补充表名**（同一服务端实例内的世界共用；编辑其他语言前需先填写 `en_us` 英文名，资源包自带翻译优先）。

## 多人游戏

考古笔记的解锁进度、收藏和日志均按玩家独立保存；客户端和服务端都需要安装本模组。
