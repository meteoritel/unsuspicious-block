# 快速上手

本流程从第一次进入世界开始，到获得考古笔记、解析仪和考古铲，然后开始记录自己的发现。

## 1. 制作考古笔记

在工作台中将一本书和一把刷子合成考古笔记。把笔记放在背包中即可使用；右键笔记可以打开界面，默认按 `C` 也可以在携带笔记时打开。

## 2. 寻找考古地点

前往包含可疑方块的遗迹，使用原版刷子进行考古。考古过程中可能发现：

- **古代金币**：古迹废墟的普通考古战利品池有 5% 概率出现。
- **失落书页**：古迹废墟的稀有考古战利品池有 8% 概率出现。

考古笔记会在你第一次发现新的战利品表或物品时逐步解锁目录和进度。

## 3. 制作两件工具

### 考古铲

配方需要 3 个铁锭、1 个铜锭和 1 根木棍。考古铲既是铁质铲子，也是后续快速发掘的专用工具。

### 可疑解析仪

配方需要 2 枚古代金币、1 个玻璃板、2 个铁锭、1 个末影珍珠、2 个红石和 1 个石英。配方查看器可以直接展示完整排列。

## 扫描与发掘

手持解析仪右键可疑方块，先查看其中的战利品。单方块扫描不消耗能量；确认后，用考古铲右键同一个方块即可直接取出战利品，不必等待完整刷拭过程。

资源充足后，可以按 `V` 切换范围扫描，寻找一片区域内的可疑方块和未开启的战利品容器。

## 用失落书页获得附魔

用 3 株瓶子草合成 3 张基页，再在锻造台中依次放入基页、书和失落书页。成品是一本随机附魔书，可能包含本模组附魔、原版附魔，或两者的组合。

## 4. 记录和收集

考古笔记会记录发现过的物品、战利品条件和地点。使用目录查看还未解锁的方向，使用日志回顾已经完成的探索，再决定下一次前往哪里。

## 5. 其他

### 万能修复材料
古代金币可以在铁砧上修复任何带耐久的工具，且不会累计附魔惩罚。

### 纹饰陶轮台
嫌陶片发掘产出太慢？可以在在陶轮台使用黏土复制已有的纹饰陶片。
