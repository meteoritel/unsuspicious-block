# 失落书页与附魔

失落书页把考古探索和四种专用附魔连接起来。每本通过失落书页锻造出的附魔书都是随机结果。

## 获取失落书页

古迹废墟的稀有考古战利品池有 8% 概率出现失落书页。考古笔记会在你发现相关战利品后记录它。

## 制作基页

在工作台中将 3 株瓶子草排成一行，可以获得 3 张基页。基页也可以单独合成为纸。

## 锻造随机附魔书

在锻造台中按以下顺序放入：

1. 基页
2. 普通书
3. 失落书页

输出为一本随机附魔书，结果可能是：

- 一本本模组附魔
- 一本原版附魔
- 一本同时包含本模组附魔和原版附魔的书

## 四种附魔

| 附魔 | 适用物品 | 效果 |
|---|---|---|
| 泥底打捞 I–III | 钓鱼竿 | 钓鱼时有概率额外打捞一份宝物；等级 I 为 20%，每提高一级增加 10%。在沼泽中会使用更偏向高价值宝物的额外战利品表。 |
| 织物采集 | 剪刀 | 剪羊时额外掉落 1–3 根线。 |
| 精准发掘 I–III | 刷子 | 刷拭可疑方块时有概率使本次战利品翻倍，分别为 28%、44% 和 60%。 |
| 化石猎手 | 镐 | 挖掘自然生成的骨块时有 50% 概率从当前维度的化石战利品表中获得额外奖励。 |

### 化石猎手的限制

化石猎手只对世界生成时记录为自然生成的骨块生效。玩家放置的骨块、机器放置的骨块和已经被处理过的骨块不会触发额外奖励；创造模式或关闭方块掉落规则时也不会发放奖励。

### 如何查看附魔效果

普通附魔书的详细效果可以查看物品提示。持有[猫之瞳](Eye-of-Cat)后，还可以在附魔台中查看每个候选附魔的完整信息。
