# 快速上手

这份指南带你从零开始制作核心工具、前往遗迹发掘古代金币与失落书页，并顺手体验淘洗、制陶与远古植物等玩法。

## 1. 制作考古笔记

在工作台中将 **1 本书** 和 **1 把刷子** 无序合成为[考古笔记](zh-Archaeology-Journal)。

- 拿在手中右键，或放在背包（含饰品栏/标本箱）中按 `C` 键即可随时打开。
- 打开背包或 JEI 界面时，把鼠标悬停在任意物品上按 `C`，可直接检索它在考古笔记中的来源。

## 2. 寻找遗迹或前往河边

前往沙漠神殿、海底废墟或古迹废墟，用原版刷子刷拭可疑方块；也可以制作一只[铜淘盘](zh-Fishing-and-Panning)，在河流群系寻找水面闪耀的**闪烁的光**长按右键淘洗。

探索过程中你会陆续获得两样关键资源：

- **古代金币**：古迹废墟普通考古池（5%）、河流淘洗、考古铲挖沙/砂砾（0.3%）或化石猎手掉落。
- **失落书页**：古迹废墟稀有考古池（8%）、河流淘洗或化石猎手掉落。

每次刷拭可疑方块、开箱、打捞或淘洗后，考古笔记都会解锁对应条目并记录下发现坐标。

## 3. 制作两件考古主力工具

### 考古铲

使用 **3 个铁锭 + 1 个铜锭 + 1 根木棍** 合成[考古铲](zh-Reader-and-Shovel)。它拥有铁铲的挖掘速度与 256 点耐久，挖沙或砂砾时会向下连续挖掘最多 3 格且自动避开可疑方块，非潜行状态下不会误挖可疑方块。

### 可疑解析仪

使用 **2 枚古代金币 + 1 个玻璃板 + 2 个铁锭 + 1 个末影珍珠 + 2 个红石粉 + 1 个下界石英** 合成[可疑解析仪](zh-Reader-and-Shovel)。

## 4. 先扫描、再直接取出

1. **单方块扫描（免费）**：默认模式下直接对着可疑方块右键，画面准星旁和左下角会立刻显示其中的物品。
2. **直接取物**：确认想要里面的战利品后，改用**考古铲**右键该方块，即可直接取出物品（无需等待漫长的刷拭）。如果主手拿解析仪、副手拿考古铲，第一次右键会先扫描，第二次右键会自动由副手取出战利品。
3. **范围扫描**：按 `V` 键切换范围模式（`3×3×3`、`5×5×5`、`7×7×7`），右键方块即可高亮一片区域内的可疑方块与未开启的战利品容器。按 `H` 键可以随时隐藏或显示扫描 HUD 面板。
4. **补充能量**：范围扫描会消耗解析仪能量，能量不足时自动消耗背包中的古代金币；你也可以潜行右键空气手动充能（每枚金币恢复 256 点能量）。

## 5. 用失落书页锻造附魔书

在工作台中将 **3 株瓶子草** 排成一行，合成为 **3 张基页**；随后在**锻造台**中从左到右放入 **基页 + 书 + 失落书页**，即可锻造出一本随机附魔书。详情见[失落书页与附魔](zh-Lost-Pages-and-Enchantments)。

## 6. 更多实用玩法

- **古代金币万能修复**：古代金币可在铁砧上为任意带耐久的物品修复 **25% 最大耐久**，且**不会累加铁砧惩罚值**；也可用于和流浪商人交易（1 金币换 5 绿宝石）。
- **复制珍贵陶片**：把已有陶片、黏土和水瓶放入[纹饰陶轮台](zh-Pottery-Wheel)即可压印复制，再进熔炉烧制成型，原陶片不会消耗。
- **把护身符放进标本箱**：在村庄武器匠箱子找到[标本箱](zh-Specimen-Box)后，可将[猫之瞳](zh-Eye-of-Cat)、考古笔记或不死图腾放入其中随身携带并保持生效。
- **种植驱怪植物与重游遗迹**：嗅探兽挖掘有 50% 概率带来[咕噜荆芥](zh-Purrmint)种子，成熟后可让苦力怕和幻翼避让；如果遗迹已被探索殆尽，还可以用火把花制成[花火粉与回溯粉](zh-Spark-and-Rewind-Dust)让结构原位重生成。
