# 标本箱

标本箱是一个五格便携容器。它既可以收纳物品，也可以让箱内部分需要“随身携带”或“装备”才能生效的物品继续发挥作用。

## 获取

村庄武器匠房屋的箱子有 30% 概率生成一个标本箱。

## 随身生效

考古笔记、猫之瞳以及部分支持饰品栏的物品，可以在标本箱内部保持“被携带”的状态。比如把猫之瞳放入标本箱后，只要标本箱仍在你的背包或饰品栏中，附魔台、铁砧和砂轮仍可获得猫之瞳的信息能力。

## 不死图腾代理（1.5.2 起）

标本箱放在背包或饰品栏中时，箱内的不死图腾同样可以救命：死亡的瞬间会自动消耗箱内的一个图腾，效果与手持图腾完全一致（保留 1 点生命，并获得再生、伤害吸收和防火效果）。

- 原版手持图腾仍然优先生效，标本箱只在手持图腾未触发时接管。
- 只消耗标本箱内部的图腾，背包里散装的图腾不受影响。

## 饰品栏联动

- Fabric 使用 Trinkets。
- NeoForge 使用 Curios。
- 安装 Artifacts 时，标本箱还可以代理兼容饰品的装备效果。

这些联动都是可选的；没有安装时，标本箱仍然可以作为普通五格便携容器使用。

## 限制

标本箱不能放入另一个标本箱，以避免容器无限嵌套。
