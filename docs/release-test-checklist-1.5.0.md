# Unsuspicious Block 1.5.0 发布测试清单

本清单用于人工测试 `1.5.0`。请分别记录 Minecraft 日志、复现步骤、实际结果、截图，以及使用的 Loader 和兼容模组版本。

猫之手、猫族羁绊、猫猫剑士、猫猫商人、猫猫信使及其衍生内容尚未完成，不属于本次发布范围，无需测试。

## 测试环境

- [ ] 使用全新世界完成一轮测试。
- [ ] 备份一个 `1.4.0` 存档，再使用 `1.5.0` 升级并完成一轮测试。
- [ ] Fabric 端安装 Fabric API，确认单人游戏可正常进入和退出世界。
- [ ] NeoForge 端确认单人游戏可正常进入和退出世界。
- [ ] Fabric 与 NeoForge 各测试一次独立服务端，至少两名玩家同时在线。
- [ ] 两端分别测试不安装兼容模组的基础环境。
- [ ] 两端分别安装 JEI 与 Jade 后测试；NeoForge 端额外安装 Lootr 回归测试。
- [ ] 分别切换简体中文和 English (US)，确认新增物品、方块、GUI 与 JEI 文本正常显示且没有裸露的本地化 key。

## 基础冒烟测试

- [ ] 主菜单模组列表显示版本 `1.5.0`。
- [ ] 新建世界、加载旧世界、退出后再次进入均无崩溃或明显报错。
- [ ] 执行 `/reload` 后考古笔记、配方、JEI 分类和新增方块仍可正常使用。
- [ ] 在独立服务端中打开考古笔记与陶轮台，确认服务端不会加载客户端类而崩溃。

## 不可疑方块

- [ ] 将一把考古铲与一个沙子无序合成，得到空的不可疑沙子，原考古铲损失 1 点耐久。
- [ ] 将一把考古铲与一个沙砾无序合成，得到空的不可疑沙砾，原考古铲损失 1 点耐久。
- [ ] 使用只剩 1 点耐久的考古铲合成，确认铲子正确损坏且不会复制或残留异常物品。
- [ ] 将空不可疑方块与一个普通物品无序合成，确认成品保存正确物品、数量和 Data Component。
- [ ] 尝试用已封存的不可疑方块继续封存，或将两种不可疑方块互相封存，确认配方不成立。
- [ ] 将封存成品交给另一名玩家，确认记录的是首次持有成品的玩家，且 tooltip 中姓名正确。
- [ ] 放置封存方块后用可疑解析仪扫描，确认能够识别封存玩家。
- [ ] 安装 Jade 后查看空方块和封存方块，确认封存内容、数量及玩家显示正确且无需扫描。
- [ ] 分别用刷子和考古铲右键不可疑方块，确认方块被破坏、工具损失 1 点耐久，并掉落原版基底和完整封存物品。
- [ ] 生存与创造模式分别测试上述交互，确认创造模式不会错误消耗工具耐久。
- [ ] 移除方块下方支撑，确认方块碎裂而不是像普通沙子一样落下，并正确掉落基底及封存内容。
- [ ] 使用普通挖掘、爆炸、活塞和区块卸载等方式破坏或更新方块，确认封存物品不会丢失或重复掉落。
- [ ] 放置后退出世界并重新进入，再破坏方块，确认封存内容和玩家身份持久化。

## 纹饰陶轮台

- [ ] 按配方使用陶瓦、铜锭和橡木木板合成纹饰陶轮台。
- [ ] 打开 GUI，确认四个纹饰槽、黏土槽、水瓶槽、输出槽、预览和进度条位置正确。
- [ ] 在任一纹饰槽放入原版纹饰陶片，再放入 1 个黏土球和 1 瓶水；等待约 8 秒后得到 1 个对应的未烧制纹饰陶片和 1 个玻璃瓶，样板陶片不被消耗。
- [ ] 将黏土球换成黏土块重复测试，确认一次得到 4 个未烧制纹饰陶片。
- [ ] 使用四个不同纹饰陶片、1 个黏土块和 1 瓶水制作未烧制纹饰陶罐，确认四面预览方向与输出一致。
- [ ] 使用 4 个黏土球替代黏土块制作陶罐，确认消耗数量和产物一致。
- [ ] 使用红砖作为一个或多个陶罐面，确认空白面能够正确保存和渲染。
- [ ] 尝试放入普通药水、空玻璃瓶、无效样板或不足 4 个黏土球，确认不会开始加工。
- [ ] 加工途中移除或替换输入，确认进度重置；占用输出槽时确认不会覆盖物品。
- [ ] 加工途中退出并重新进入世界，确认输入不会丢失，进度恢复行为不会导致重复产物。
- [ ] 破坏装有物品的陶轮台，确认所有输入、输出和玻璃瓶完整掉落且不重复。
- [ ] 将未烧制纹饰陶片放入熔炉，确认烧成对应原版纹饰陶片；无有效纹饰数据时应返还红砖。
- [ ] 将未烧制纹饰陶罐放入熔炉，确认烧成原版纹饰陶罐并保留四面纹饰。
- [ ] 放置未烧制纹饰陶罐，检查顶部、侧面、底部、相邻方块接缝和不同光照环境，没有异常遮光或缺面。

## 漏斗自动化

- [ ] 从顶部漏斗输入黏土和水瓶，确认能够进入正确槽位，纹饰样板不会从顶部误入。
- [ ] 从侧面漏斗输入纹饰样板、黏土和水瓶，确认各物品进入允许的槽位。
- [ ] 从底部漏斗抽取成品和玻璃瓶，确认不能抽走仍在使用的输入。
- [ ] 在陶轮台正下方放置漏斗，确认加工完成时成品与玻璃瓶会优先直接进入漏斗。
- [ ] 将下方漏斗或目标容器填满，确认无法送出的成品和玻璃瓶留在陶轮台内，不会消失或复制。
- [ ] 连续提供多组材料运行至少 10 次，确认每轮耗时、消耗量和产出量稳定。
