# 猫族关系系统设计

状态：设计已定稿，首轮分阶段实现已完成；正式结构与三类 NPC 职业装饰模型仍使用占位资产。

## 1. 体验目标

猫族关系是玩家通过长期善待、陪伴和保护猫，与整个猫族建立关系的支线系统。猫之手是猫国信物与恩惠媒介，不是需要升级的装备。

核心循环：

`探索猫国结构取得信物 -> 建立猫族关系 -> 与猫及村庄产生正负互动 -> 提升猫族羁绊 -> 解锁阶段恩惠 -> 接触猫国灵体 -> 维持封顶关系与猫之九命`

## 2. 系统入口与猫之手

- 由用户设计一座猫国专属结构，每座结构至少生成一件未绑定猫之手。
- 结构战利品全服共享、先到先得，不为每位玩家单独生成。
- 玩家首次绑定猫之手时建立猫族关系；此前行为不记录、不追溯。
- 关系建立后，即使未携带猫之手，猫族羁绊仍随行为正常增减。
- 猫之恩惠、猫猫信使、猫之九命与猫猫商人资格需要随身携带本人猫之手。
- 猫之手首次进入个人携带范围时绑定玩家 UUID，之后不自动改绑。
- 他人可以持有绑定信物，但无法使用或改变归属；Tooltip 显示原主人。
- 原信物遗失后，另一件空白猫之手可绑定同一玩家，并继续原有关系。
- 如果玩家已经随身携带本人信物，新取得的空白猫之手保持未绑定，方便转赠。
- 多件本人信物不叠加效果。

个人携带范围包括：

- 原版玩家物品栏、快捷栏、盔甲栏和副手。
- Trinkets / Curios 饰品栏。
- 随身携带或装备的标本箱第一层内容。

末影箱、世界容器、其他玩家背包与他人绑定信物不计入。

### 占位结构与战利品

- 正式猫国结构由用户后续设计；首轮实现使用一个带战利品箱的占位结构打通生存获取路径。
- 占位箱使用 Loot Table `unsuspiciousblock:chests/hand_of_cat_cache`。
- 每个箱子固定生成 `1` 件未绑定猫之手，不再对信物本身进行概率判定。
- 猫类补给池抽取 `2–4` 次：生鳕鱼、生鲑鱼、线、羽毛、兔子皮、金粒。
- 猫国遗物池抽取 `1–2` 次：古代金币、失落书页、命名牌、幻翼膜、经验瓶或空结果。
- 稀有彩蛋池抽取 `1` 次：`minecraft:music_disc_cat`、钻石、兔子脚或大概率空结果。
- 结构模板、生成群系、间距和最终装饰在用户提供正式资产后替换；Loot Table ID 与猫之手保底规则保持稳定。

## 3. 猫族羁绊与阶段

猫族羁绊范围固定为 `0–100`，当前数值实时决定阶段，不保留历史最高阶段，也不设置降级缓冲。

| 数值 | 阶段 | 猫之恩惠 |
|---:|---|---|
| `0–19` | 初识 | 猫的眼 |
| `20–39` | 亲近 | 猫之威慑 |
| `40–59` | 信赖 | 轻步 |
| `60–79` | 眷顾 | 柔软肉垫 |
| `80–99` | 猫国贵客 | 猫国往礼 |
| `100` | 猫国挚友 | 猫之九命、猫猫商人资格 |

恩惠只在阶段边界解锁或收回，不使用阶段内部的额外数值阈值。普通村民交易降低 `20%` 的旧能力移除。

## 4. 羁绊猫

- 玩家名下所有驯服猫均为羁绊猫，包括取得猫之手前已经驯服的猫。
- 新驯服猫自动成为羁绊猫，数量不限。
- 羁绊猫没有独立好感数值，共同参与玩家的全局猫族羁绊。
- 陪伴入睡、持续坐卧等行为只奖励猫的实际主人。
- 猫国灵体不是羁绊猫。

## 5. 正向行为

| 行为 | 变化 | 独立冷却 | 附加条件 |
|---|---:|---:|---|
| 有效喂食任意普通猫 | `+5` | `10 min` | 实际消耗有效猫食 |
| 成功驯服猫 | `+10` | `10 min` | 同次交互不再叠加喂食奖励 |
| 与羁绊猫一同入睡 | `+20` | `5 min` | 每次睡眠结算一次 |
| 羁绊猫持续坐在床、箱子或燃烧熔炉上 | `+10` | `20 min` | 连续坐定 `30 s`；开始和结算时主人均在猫周围 `7` 格内 |
| 成功击退袭击 | `+20` | `10 min` | 必须是实际袭击胜利 |

- 不增加“击杀伤害羁绊猫的敌对生物”行为，因为原版敌对生物很少主动索敌猫。
- 一次交互最多结算一种正向行为。
- 普通喂食、治疗、繁殖或失败的驯服尝试，只要实际消耗有效猫食，均按喂食结算。
- 冷却只在行为有效时刷新；距离失败、无效交互或尚未建立关系不占用冷却。
- 封顶时的有效行为仍刷新冷却，防止玩家刚跌出封顶便立即恢复。
- 各行为冷却独立并持久化，退出服务器不重置。

## 6. 负向行为

| 事件 | 变化 | 去重规则 |
|---|---:|---|
| 玩家伤害任意普通猫 | `-5` | 每次有效伤害结算 |
| 玩家杀死任意普通猫 | 总计 `-50` | 覆盖同次攻击的 `-5` |
| 玩家的羁绊猫死亡 | `-10` | 仅在并非主人亲手击杀时结算 |
| 玩家自身死亡 | `0` | 不再影响猫族羁绊 |

- 主人杀死自己的羁绊猫时总计扣除 `50`，不叠加伤害与羁绊猫死亡扣分。
- 其他玩家杀死羁绊猫时，主人扣除 `10`，击杀者扣除 `50`。
- 同一伤害链只采用最严重结果。
- 负向行为无冷却；关系建立后不要求携带猫之手。

## 7. 阶段恩惠

### 猫的眼

- 黑暗中提供夜视，离开黑暗后自然淡出。
- 无玩家开关。

### 猫之威慑

- 苦力怕主动回避玩家。
- 幻翼不再为玩家生成，也不把玩家作为攻击目标。
- 单一快捷键同时控制两部分。

### 轻步

- 开启时不踩坏耕地，也不触发压力板与绊线。
- 单一快捷键控制整个轻步恩惠，关闭后全部恢复原版行为。

### 柔软肉垫

- 减少 `80%` 摔落伤害。
- 正常移动可跨上约 `1.25` 格；潜行时取消额外跨步高度。
- 无玩家开关。

### 偏好与撤销

- 威慑和轻步开关由服务端持久化。
- 降级或信物离身只暂停能力，不重置偏好。
- 重新解锁或重新携带本人信物时按原偏好恢复。
- 阶段下降时立即撤销属性、效果与 AI 影响。

## 8. 猫猫信使与猫国往礼

- 玩家处于猫国贵客或猫国挚友阶段、携带本人信物，且羁绊猫成功触发原版晨礼时召唤。
- 每名玩家每次睡眠最多一只信使；其他羁绊猫仍可给予原版晨礼。
- 信使执行“显现 -> 穿墙接近 -> 致意 -> 投放特殊礼物 -> 消散”。
- 特殊礼物额外提供，不替换原版猫礼物；落地后立即作为普通世界掉落物。
- 成功投放才结算完整送礼。玩家离线、死亡、切换维度或流程超时均不结算。
- 召唤时满足猫国贵客即可完成礼物配送；投放时仍为 `100` 才补充一条猫之九命。
- 每名玩家同时最多存在一只猫猫信使。
- 礼物内容继续使用标准 Loot Table。

## 9. 猫之九命与剑士猫猫

- 玩家首次成为猫国挚友时获得 `1` 条命。
- 处于 `100` 时，每次猫猫信使成功送礼增加 `1` 条命，上限 `9`。
- 猫族羁绊低于 `100` 时立即清空全部命数。
- 致命伤害先尝试原版不死图腾；图腾未触发时才使用猫之九命。
- 虚空死亡不触发猫之九命。
- 触发后恢复满生命、清除所有负面效果，并获得 `2 s` 纯无敌缓冲。
- 消耗最后一条命不会清空猫族羁绊。

剑士猫猫规则：

- 在玩家附近安全位置生成，默认持续 `300 ticks`（`15 s`），具体寿命由召唤方传入。
- 高伤害、不会受伤、不产生自身掉落、不拾取物品。
- 搜索主人周围 `24` 格的敌对生物。
- 永远排除主人及其他玩家、村民、羁绊猫、驯服生物与中立生物。
- 若致命伤害由生物造成，优先攻击该生物；没有生物来源时跳过此优先级。
- 后续优先攻击正在以主人为目标的敌对生物，再选择最近目标。
- 每名玩家同时最多一只；九命再次触发时刷新寿命并重新索敌，不叠加生成。
- 目标正常掉落物品和经验，但不记为玩家亲手击杀。
- 主人离线时消散。

默认战斗参数：

| 参数 | 默认值 |
|---|---:|
| 攻击伤害 | `12` |
| 攻击间隔 | `20 ticks` |
| 移动速度 | `0.5` |
| 攻击击退 | `0.4` |
| 索敌范围 | `24` 格 |
| 默认持续时间 | `300 ticks` |
| 九命触发后的玩家无敌缓冲 | `40 ticks` |

剑士猫猫不限制总击杀数，由索敌范围、攻击间隔与持续时间共同控制收益。

## 10. 猫猫商人

### 经济

- 交易数据由自定义 Datapack JSON 提供并支持 `/reload`。
- 主要收取古代金币，作为中后期金币消耗出口。
- 允许少量高成本、受次数限制的金币产出交易，例如 `30 条鱼 -> 1 枚古代金币`。
- 可用物品 Tag 表示任意鱼类等交易输入。
- 商品库存与次数限制在同一商人实例上全服共享。

### 默认交易清单

猫猫商人每次生成 `6` 项交易：产币池抽取 `1` 项、常规池抽取 `3` 项、稀有池抽取 `2` 项。交易次数与库存属于商人实例并由全服玩家共享；一只商人通过全部产币交易最多反向产出 `2` 枚古代金币。

| 交易池 | 输入 | 输出 |
|---|---|---|
| 产币 | `30` 条任意鱼 | `1` 枚古代金币 |
| 产币 | `32` 根线 | `1` 枚古代金币 |
| 产币 | `16` 张兔子皮 | `1` 枚古代金币 |
| 产币 | `8` 张幻翼膜 | `1` 枚古代金币 |
| 常规 | `1` 枚古代金币 | `3` 张幻翼膜 |
| 常规 | `1` 枚古代金币 | `2` 个兔子脚 |
| 常规 | `2` 枚古代金币 | `1` 个命名牌 |
| 常规 | `1` 枚古代金币 | `4` 个经验瓶 |
| 常规 | `2` 枚古代金币 | `1` 张失落书页 |
| 常规 | `2` 枚古代金币 | `1` 个随机陶片 |
| 稀有 | `4` 枚古代金币 | `1` 张随机唱片 |
| 稀有 | `5` 枚古代金币 | `1` 个随机盔甲纹饰模板 |
| 稀有 | `3` 枚古代金币 | `1` 颗钻石 |
| 稀有 | `4` 枚古代金币 | `1` 张 `minecraft:music_disc_cat` |

- 每条交易仍有数据驱动的次数限制，默认 JSON 可独立配置权重、最大使用次数与条件。
- 可选 `conditions` 支持 `min_cat_bond`、`max_cat_bond` 与 `dimensions` 白名单；条件在商人生成、抽取库存时评估。
- 随机盔甲纹饰模板只包含盔甲纹饰模板，不包含下界合金升级模板。
- 任意鱼与三类随机商品均通过 Item Tag 解析，不在交易加载器中硬编码物品集合。

### 生成与访问

- 使用独立生成器和独立概率，不影响原版流浪商人。
- 每 `24000 ticks` 尝试一次，初始成功率为 `25%`；失败后依次提高至 `50%`、`75%`，成功后重置为 `25%`。
- 不采用原版 Wandering Trader 的额外 `1/10` 随机判定。
- 候选玩家必须为猫国挚友，并携带本人猫之手。
- 参考 Wandering Trader 在候选玩家周围 `48` 格内最多尝试 `10` 个位置，落点必须属于有效村庄，优先靠近集合点或钟。
- 每个 `ServerLevel` 同时最多一名猫猫商人。
- 默认驻留 `48000 ticks`（约 `40 min`），寿命由生成器传入；命名、围困或载具不能使其永久存在。
- 候选人离开或降级不会让已生成商人立即消散。
- 每次打开交易时重新检查玩家是否仍为猫国挚友且携带本人信物。
- 所有满足资格的玩家均可交易；不合格玩家只能看见实体。
- 不生成羊驼，不使用村民职业、工作站、补货或村庄声望。

## 11. 猫国灵体架构与表现

- 从现有 `GhostCat` 提取共享 `SpiritCat` 基类。
- 公共能力包括灵体物理、同步、无碰撞、无敌、显现/消散与基础渲染。
- 猫猫信使、剑士猫猫、猫猫商人使用三个独立实体类型和独立 Goal。
- 保留 `unsuspiciousblock:ghost_cat` registry ID 给猫猫信使，降低测试世界迁移成本。
- 当前统一使用原版猫模型占位。
- 最终仍使用原版猫基础体型，通过用户制作的职业装饰区分；剑士猫猫嘴叼钻石剑。
- 实体不硬编码消散时间，每次召唤时传入。
- 公共实体与玩法逻辑位于 `common/`；Fabric 和 NeoForge 只负责注册及事件接入。

## 12. 玩家反馈

### Tooltip

- 空白信物显示“未绑定”。
- 本人信物显示归属、猫族羁绊、羁绊阶段和命数；按住 Shift 查看阶段恩惠。
- 他人信物只显示归属，不错误显示查看者自己的关系状态。
- 无法解析玩家名时使用绑定时名称或缩略 UUID。

### HUD 与事件

- 仅携带本人信物时显示现有快捷栏侧边 HUD。
- 保留猫爪、羁绊数值和命数角标；猫爪叠色与羁绊数值使用相同阶段色，封顶保留呼吸效果。
- 羁绊有效增减使用 Action Bar；冷却拦截不提示。
- 阶段升降使用 Toast，列出新阶段与获得或失去的恩惠。
- 从 `100` 降低时明确提示全部命数消失。
- 首次绑定显示 Toast；额外空白信物保持安静。
- 所有文本同步维护 `en_us` 与 `zh_cn`。

| 阶段 | HUD 颜色 |
|---|---|
| 初识 | 灰银 `#B0BEC5` |
| 亲近 | 嫩绿 `#81C784` |
| 信赖 | 青色 `#4DD0E1` |
| 眷顾 | 暖金 `#FFD54F` |
| 猫国贵客 | 珊瑚粉 `#FF8A80` |
| 猫国挚友 | 淡紫 `#C5A3FF`，带呼吸效果 |

九命角标继续使用固定青色，不随阶段变化。阶段始终同时显示数值或名称，不以颜色作为唯一信息来源。

## 13. 数据驱动与配置

Datapack 管理：

- 猫猫信使 Loot Table。
- 猫猫商人交易 JSON。
- 猫之手结构、结构 Loot Table、Worldgen 与 Item Tag。

三类随机商品通过模组包装 Tag 统一提供：

- `unsuspiciousblock:random/pottery_sherds`
- `unsuspiciousblock:random/music_discs`
- `unsuspiciousblock:random/armor_trim_templates`

包装 Tag 优先包含 Fabric 与 NeoForge 共同采用的 `c:` Conventional Tag；没有可靠通用 Tag 时，包含对应 Vanilla Tag 或当前显式物品列表作为保底。陶片优先复用 `minecraft:decorated_pot_sherds`，盔甲纹饰优先复用 `minecraft:trim_templates`，唱片包装 Tag 默认保留当前 `19` 张唱片并可选纳入 `c:music_discs`。Datapack 可通过扩展包装 Tag 增加其他模组内容。

现有 Loot Table ID 保持兼容，并改为从包装 Tag 等概率抽取：

- `unsuspiciousblock:usb/random_pottery_sherd`
- `unsuspiciousblock:usb/random_music_disc`
- `unsuspiciousblock:usb/random_armor_trim`

猫猫商人的随机商品同样复用这些包装 Tag，不维护第二份硬编码列表。

服务端配置管理：

- 羁绊行为数值、冷却、坐卧时间与距离。
- 夜视亮度、摔落减伤与跨步高度。
- 剑士猫猫战斗参数、复活缓冲与持续时间。
- 猫猫商人生成参数和驻留时间。
- 猫猫信使阶段时长与总超时。

固定规则包括：

- `0–100`、六个阶段与恩惠归属。
- UUID 绑定与替代规则。
- 正负事件去重优先级。
- 封顶跌落清空命数、图腾优先和虚空排除。
- 剑士猫猫排除所有玩家。
- 每名玩家同时一只信使和一只剑士猫猫。

客户端只配置 HUD 显示；威慑与轻步为服务端玩家偏好。

## 14. 旧存档迁移

- 保留外层 NBT 键 `unsuspiciousblock_cat_favor`，新增内部 `data_version`。
- 旧 `favor` 迁移为 `cat_bond`。
