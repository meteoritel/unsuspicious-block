# 工具栏图标图集

本文档记录 `assets/unsuspiciousblock/textures/gui/toolbar_icons.png` 的固定槽位映射，供
`IconButton.Icon`、工具栏及其他 GUI 组件统一取样。

## 1. 图集规格

| 项目 | 值 |
|---|---|
| 图集尺寸 | `81 x 27 px` |
| 单个图标尺寸 | `9 x 9 px` |
| 网格 | 9 列 x 3 行 |
| 坐标原点 | 左上角 |
| 行列编号 | 从 0 开始 |
| UV 计算 | `u = column * 9`，`v = row * 9` |

渲染单个图标时，纹理尺寸应传入 `81 x 27`，取样区域固定为 `9 x 9`。

## 3. 使用约束

- 新图标只能追加到预留槽位，已有槽位不得换位，避免现有按钮显示错误图标。
- 代码使用行列坐标保存映射，不直接散落硬编码 UV；实际 UV 统一由行列乘以 `9` 得到。
- 图标语义与具体按钮文案分离。同一图标可复用，但按钮仍须提供对应的本地化 Tooltip。
- 纹理使用像素风格取样，不进行平滑过滤，避免 `9 x 9` 图标边缘模糊。

## 4. 日志页面映射

日志工具栏的操作按钮已全部迁移至图集绘制（例外：日志详情页的返回按钮
仍使用 ASCII 字符 `'←'` 构造）：

| 操作 | 图标枚举 |
|---|---|
| 排序方向 | `ARROW_UP` / `ARROW_DOWN` |
| 按时间分组 | `CLOCK` |
| 按维度分组 | `DIMENSION` |
| 按群系分组 | `BIOME` |
| 按备注状态分组 | `PENCIL` |
| 日志条目配置 | `GEAR` |
| 清除当前表 | `TRASH_EMPTY` |
| 清除所有日志 | `TRASH_FULL` |
| 进入 / 退出批量选择 | `SQUARE` / `GROUP` |
| 确认批量操作 | `CHECK` |
| 编辑日志备注 | `PENCIL` |

`IconButton` 与直接读取该图集的 `PotteryWheelModeButton` 均须使用 `81 x 27` 作为纹理尺寸。
