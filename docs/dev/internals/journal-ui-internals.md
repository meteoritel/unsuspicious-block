# 笔记 GUI 内部机制

> 考古笔记与战利品表管理界面的内部结构：组件分层、唯一输入与焦点路由、右页与工具栏组装、网格与日志展示规则、场景详情与浮层交互，以及本地阅读状态持久化。
> 本文件不参与主任务导航，由[客户端与 GUI](../subsystems/client-ui.md)按需链接；UI Kit 公开接口与兼容性规范见[UI kit 公开 API 与兼容策略](ui-kit-api.md)。

## 1. 组件职责与输入拓扑

| 组件 / 目录 | 职责 |
|---|---|
| `ArchaeologyJournalScreen` | 消费 UI Kit `UiScreen` 的根界面：持有唯一 `UiInputRouter`、选择当前顶层作用域、管理页面返回历史栈与返回快照 |
| `UiScreen.viewport()` / `JournalBookBackground` | 换算逻辑书页坐标与缩放比例，使用 UI Kit 精灵图层绘制宿主书本贴图 |
| `journal/catalog/` | 聚合 `JournalViewModel`、查询状态、工具栏、目录面板与展示投影；根 Screen 提交同批分类/行/选择，模型只计算投影 |
| `CatalogToolbar` / `LogToolbar` | 维护搜索草稿、防抖输入、排序、过滤与日志批量操作入口 |
| `CatalogPanel` / `RightPageContainer` | 组装左页目录面板与右页（`INTRO` / `ARCHAEOLOGY` / `LOG` / `SCENARIO`）内容树与侧边书签/翻页控件 |
| `JournalControls` / `UiAtlas` / `ScenarioAtlas` / `UnsuspiciousUiTheme` | 管理图标与控件皮肤图集、场景专用底板图集，构造侧签/书签/翻页/行热点皮肤并维护羊皮纸与深色主题 |
| `JournalOverlays` | 持有当前打开的场景浮层/灯箱的准备与退出清理回调 |
| `journal/` / `RightPageContainer` | 类型化捕获与恢复阅读位置，生成持久投影；NBT 编码集中在 `JournalReadingStateCodec` |
| `support/` | 提供搜索、排序、格式转换、概率显示、本地持久化与网络请求适配 |

### 1.1 输入路由与焦点规则

- **单一根路由与逻辑坐标**：`ArchaeologyJournalScreen` 只持有一个 UI Kit 路由器，所有渲染、指针坐标与拖动增量均经 `UiScreen.viewport()` 换算；`JournalContent` 的 `UiChildren` 按绘制层序登记目录、欢迎页/活动右页与顶层 widgets；Tab 独立保留 widgets → 目录 → 右页顺序。命中、焦点、普通字符、配对释放、退出通知和布局从同一成员树派生，控件与行热点按稳定业务键复用。
- **焦点与页面回退**：当前顶层 `UiInputScope` 拥有唯一输入与焦点权。目录列表与条件文档区各贡献自身的键盘停靠点；鼠标点击可切换逻辑焦点，轮廓随键盘模式显隐。笔记根 scope 绑定统一页面回退：响应常见鼠标回退侧键，或文本编辑与顶层浮层未消费的 `Backspace`。两种入口共用阅读历史，没有有效历史时关闭笔记；回退只恢复阅读状态，不撤回已提交的网络请求。事件结束的普通导航记录通过回退版本跳过本次恢复，避免重复入栈。通用输入配对与生命周期见 [UI Kit](ui-kit-api.md)。
- **按钮激活与悬停命中**：按钮遵循“按下并同目标释放”才执行动作，拖出范围释放取消。`UiPointerHit` 是 Tooltip 与 JEI 物品查询的统一来源（网格、介绍页与日志详情在准备阶段将已解析的 `ItemStack` 写入 `UiPointerHit.Row.key`，不再二次反查坐标）；当模态框、文本框或持续拖动占用输入时，底层 JEI 悬停查询返回空栈。
- **只读布局**：根 `layoutNodes()` 沿当前输入树聚合控件与自绘目录行，提供 `table/<id>`、`log/<entryId>`、日志坐标动作及工具栏的稳定 key。目录行复用实际滚动几何并裁剪到视口，锁定条目保留隐藏语义；根统一投影到原版 GUI 坐标。运行探针与截图见[核心探针](../../../tools/probes/README.md)。
- **固定画布**：双页保留最小逻辑尺寸 `412 × 256`，根使用可容纳画布的整数物理像素倍率，GUI 设置决定放大上限。缩小窗口可降低整数倍率，实际像素不足 `1×` 时连续缩小；正文随书页倍率绘制，Tooltip 由 Kit 转入原版 GUI 空间。统一接入契约见 [UI Kit](ui-kit-api.md#31-普通页面与考古笔记)。

### 1.2 右页装配 (`RightPageContainer`)

右页替换通过根路由器登记新成员并结束已离场分支的交互。窗口 resize 重新摆放现有右页、书签和覆盖面，保留阅读位置。考古笔记按书页、活动场景浮层或灯箱、确认框登记呈现顺序，顶部作用域决定输入、悬浮与提示。场景推荐正文使用 Kit 文档视图，根资源失效通知活动覆盖面重新排版。

- `RightPageContainer` 实现 `UiInputContainer`，稳定成员集合只登记当前活动面板；切页签或日志模式时结清旧交互并传播本地退出。通过局部 `PageDescriptor` 绑定右页各 Tab 的内容面板、书签皮肤、指示器位置及切换生命周期回调，并通过 `chromeControls()` 将书签与翻页按钮统一交给 Screen 注册（分类首页时 Screen 通过 `setChromeAvailable(false)` 整体隐藏）。实际切换 Tab 时，若逻辑焦点属于书签，焦点跟随新的活动书签；同 Tab 数据刷新保留正在遍历的焦点。
- **分页状态由活动面板自有**：`ARCHAEOLOGY` 由 `ArchaeologyPage` 组合 `ItemGridPanel` 与 `ScenarioPanel`（同一实际成员集合按 grid → scenario 登记，场景栏命中优先，Tab 焦点顺序为网格 → 场景栏）；`LOG` 按列表/详情模式切换面板。分页动作调用活动面板的 `setPage` / `changePage`，由面板自身维护脏状态、页码边界并在准备阶段同步更新翻页按钮状态。

## 2. 目录面板与追踪管理界面

### 2.1 左页分类与表目录

- 欢迎页统计读取客户端日志镜像，最近记录的表名优先取目录。分类和表目录在首次目录同步后即可浏览，玩家进度决定表名可见性与解锁数。已选表的静态候选可在基准模拟期间展示，收到测量后保持同表阅读位置。
- 分类首页使用两列卡片网格，战利品表目录使用支持独立展开的树形行列表；两者均由 `UiScrollView` 驱动连续滚动，绘制、命中与 Tooltip 共用同一几何投影。
- 目录的实际偏移与阻尼目标由 kit 持有。`CatalogPanel` 用同一行格几何绘制、命中和导出快照。滚轮提交实际像素量，键盘调用 `ensureIndexVisibleSmoothly`，阅读恢复立即定位。释放时以实际分类 ID 或目录条目出现路径及热点类型匹配按压。 [UI kit 接入规范](ui-kit-api.md#31-普通页面与考古笔记)
- 展开父表展示其直接子表。从父表跳转时沿当前引用路径定位。全局搜索及默认定位优先使用表自己的顶层入口，其余表沿从分类顶层出发的最短路径定位。
- 对外暴露的滚动偏移 API（`getScrollOffset` / `setScrollOffset`）保持以条目为单位，内部按当前视图步长转换为像素并在模式切换或窗口变化后重新钳制。

目录展示记录位于 `journal/catalog/CategoryEntryData` 与 `CatalogEntryData`。模型重建不接收面板，根 `syncCatalogProjection()` 统一提交分类或行并使选择可见；搜索、导航和数据刷新复用该装配点。动态文本缓存 `text/PanelTextMetrics` 由具体面板持有，按业务内容、语言资源和 Font 身份失效。

### 2.2 追踪管理页面 (`LootTableManagementScreen`)

从笔记左侧管理侧签进入，可浏览规则来源、目录收录状态和多语言名称。

- **数据来源与权限**以服务端管理快照为准，包含目标规则、实际目录收录、父表与配置版本。单表修改和世界规则页共用服务端收录预览与应用结果。权限见[配置与联动](../foundation/config-and-integrations.md#22-配置界面与热重载)。
- **浏览**使用命名空间路径树，搜索与最近遇到使用平铺结果。表名与完整 ID 同时可见。单击行或按方向键选择，单击三角、双击目录行或按 Enter 切换展开状态。详情体使用 `UiFormBody` 支持滚动与 Tab 焦点跟随。
- **世界规则**左侧显示内置规则名称，右侧提供单条启用与禁用开关，可编辑时悬停查看匹配路径。「全部启用」和「全部禁用」修改当前草稿，从全部禁用状态可重新启用单条规则。出现可核对的新服务端版本时，批量操作旁显示「核对当前设置」。
- **表名编辑**在管理页的独立区域处理。关闭语言选择先回到表名编辑，表名编辑的「返回收录管理」和 Esc 回到追踪管理并保留草稿。导入可选择语言、核对各项变化、为歧义旧键指定完整 ID，并在套用导入项时处理已有草稿。保存后保留失败或继续编辑的草稿，冲突显示当前服务端值。

## 3. 网格、介绍与日志面板

### 3.1 网格展示与未解锁隐藏规则 (`ItemGridPanel`)

`ItemGridPanel` 将条目按「物品标签组 → 直接子表入口 → 直属物品」顺序生成逻辑序列并切片为 `visibleCells` 投影，渲染、点击、Tooltip 与 JEI 命中全部读取同一投影。

| 条目状态 | 网格与入口展示 | Tooltip 行为 |
|---|---|---|
| **未发现物品** | 统一显示未知图标与「待解析」 | **严禁剧透**物品名称、概率、声明触发率或具体路径；普通物品卡片不提供点击跳转 |
| **已发现物品** | 固定显示优先级：`不可用状态（需要条件 / 未知） → 可展示的声明触发率 → 模拟值`（零命中显示「未命中」，静态不可达才显示 `0%`） | 并列显示声明触发率与模拟值，并渲染带获取条件和折叠效果的函数树 |
| **直接子表入口** | 至少有一项后代物品已发现后才解锁名称与预览 | 条件直接读取服务端下发的 `ChildTableProbability.conditions`（含注入门槛），客户端不自行重推 |

> 物品标签组（Tag）读取本组成员、子表读取其后代物品闭包；子表物品不混入父表网格或父表搜索，介绍页（`Intro`）则递归合并全部后代按签名去重展示。

### 3.2 日志列表、详情与编辑子页

- 日志分页、时间/维度/群系/备注分组、批量选择模式与选中条目由业务模型维护；`UiControlGroup` 按业务键复用列表行、复制坐标与备注按钮。
- 单条删除、清空当前表与清空全部日志均先弹出 UI Kit 确认模态（`UiModalStack`）再发送网络请求。
- `JournalLogNoteEditScreen` 与 `JournalLogRetentionScreen` 稳定持有编辑框与输入作用域（窗口大小变化仅重算排版）：备注严格校验服务端 `500` UTF-16 字符上限，保留设置校验自动保留 `>= 1`、一次性裁剪 `>= 0` 后才发包，返回后恢复子页打开前的阅读快照。日志保留正文使用 `UiFormBody`，数字过滤、提交范围与两种网络请求留在页面。

## 4. 场景条件页与文档动作

- **连接内动作所有者**：`JournalClientConnection` 创建、tick 推进并退役 `ScenarioSession`；入站消息仍按连接 epoch 在偏好加载后应用。选择、按输入缓存、模拟票据、辅助请求与提示由会话管理；退役会话的旧浮层动作停止提交。进程内序号持续递增，换连接时保持票据隔离。
- **完整单表快照**：`ScenarioTableSnapshot` 聚合结构/选项、当前条件与参数、当前测值、inputKey、状态、失败与提示、推荐预览、目标展示及单表 revision。`RightPageContainer` 从玩家进度派生的物品与子表条目构造可见性和名称，再提交会话供网格与场景阅读共用。未发现目标使用未知图标与名称，跳转与推荐按同一可见性开放。
- **局部失效**：选择与当前测值改变时只失效所属表投影；请求等待、推荐和提示只推进所属表呈现。其他表的 `TableDefinition` 保持对象复用，目录消费者由 `projectionRevision` 更新概率排序与搜索。发现变化更新目标展示并推进快照身份；`ScenarioDetailPanel` 按单表快照、语言与本地文档脏状态复用内容，字号/宽度排版由 reader 管理。
- **面板分工**：`ScenarioPanel` 位于网格页顶部，提供已启用条件摘要及参数、计算和条件入口。表名由左侧目录承担，`ScenarioDetailPanel` 只展示当前输入、条件结构与组合状态，具体概率仍在网格；场景页不承担页面回退或恢复默认动作。`ScenarioPageBuilder` 从传入快照生成状态图标、条件清单与目标分支树；动作回调进入会话。条件浮层提供“清除条件”文字操作，条件灯箱的工具栏提供缩放与平移复位。
- **条件与推荐语境**：分支徽章按完整树、当前工具附魔及幸运即时求值，区分阻塞、机会和未知。组内稳定选择可见且可推荐的成员，按钮明确“为〈目标〉推荐此分支”并发送该成员引用；网格保留目标级推荐。观测与 tag 分支显示能力说明。条件语义、候选签发与求解边界见[战利品表机制](loottable-mechanics.md#32-条件组合模型与按需规划-simulationscenarioplanner)。
- **文档与灯箱共源**：`ScenarioDetailPanel` 持有 `UiDocumentView` 和业务文档，`ScenarioExpandedOverlay` 复用同一节点结构；灯箱复制节点并保留提示，关闭节点动作以便在文字和图标上都能直接拖动。快照变化时页内与放大阅读获得相同内容；kit reader 负责折行、滚动、命中、动作导航及配对激活，契约见[UI kit 文档阅读](ui-kit-api.md#33-文档阅读与业务呈现)。条件 offset 按表 ID 捕获进阅读快照。
- **测值展示**：完整规范化 inputKey 命中对应参数/档位缓存时才复用测值，其他输入保持未知；旧有效输入保留缓存供切换对比。请求状态与缓存命中各有身份，晚到结果保持当前选择。线路字段与终态见[网络与同步](../foundation/network.md#31-通用协议原则)。
- **首次查看**：选择已解锁的表时，场景会话主动取回或请求待算的基准结果。受幸运影响的表在新连接中以幸运 0 初始化，保留可用的已保存条件、工具与附魔，并自动请求该初始组合的结果。随后提交的自定义选择按所选应用动作处理。

## 5. 场景浮层与灯箱 (`JournalOverlays`)

所有浮层使用 `UiOverlay`、灯箱使用 `UiLightbox`、确认提示使用 `UiModalStack`；根屏幕选择顶层 `UiInputScope`，由 kit 处理遮罩、焦点归还与迟到事件隔离。

条件、参数和推荐共用 `ScenarioSession.Draft`：会话身份、表、generation/hash、基础选择 revision 与完整 `SimulationInput`。`applyDraft` 校验并保存后查询缓存，`applyDraftAndSimulate` 校验并保存后建立该输入的模拟票据。版本、范围或基础选择冲突时返回具体错误，浮层保留草稿和原因；成功才关闭。条件浮层转入参数编辑时继续沿用原草稿版本。网络晚到拒绝属于已提交请求的状态，选择保持已提交值。

| 浮层类 | 职责与交互约束 |
|---|---|
| `ScenarioConditionOverlay` | 预览原子条件勾选与 Tooltip，提供清除条件、同步自身、参数、应用并计算、仅应用和取消；确认通过会话提交整份草稿 |
| `ScenarioParamsOverlay` | 编辑幸运数值、工具和附魔等级。幸运滑条以当前选择回填，轨道下方标出 0 的位置。条件及固定抽样档位随草稿通过会话动作提交 |
| `ScenarioRecommendationOverlay` | 预览请求目标、分支范围、实际候选与 pathId，并比较条件/参数变更；未发现候选保留未知名称。客户端核对范围、版本、基础输入、签发域与见证归属后接收；应用沿用请求时的草稿版本，失败原因留在浮层。关闭、切表、切输入或内容失效时取消旧辅助交互 |
| `ScenarioExpandedOverlay` | 为 `UiLightbox` 装配同源条件文档的只读副本，按窗口适配初始缩放；文字和图标区域均可自由拖动，支持工具栏切换拖拽锁定、滚轮缩放、resize 钳制与 Esc 关闭，保留页内滚动位置 |

图标、徽章与通用控件皮肤取自 `ui_atlas.png`；场景页、条件分区和合集卡片底纹由 `ScenarioAtlas` 从 `scenario_panels.png` 提供。分区与 UV 见[UI 图标与控件皮肤图集](toolbar-icon-atlas.md)。

## 6. 阅读状态与本地持久化

`RightPageContainer` 是右页阅读状态的唯一捕获/恢复入口。`ReadingState` 使用具名 `PagePositions` 保存介绍、网格、日志列表和日志详情页号，同时携带 Tab、active tag、日志身份、批选与按表条件偏移。集合不可变，NBT 只存在于 codec 与存储边界。面板布局随直接构造和 `applyLayout` 完成。

`UiStateSnapshot` 聚合这份阅读状态和目录、工具栏字段，在 resize、同 Screen 子页返回与历史回退时复用。普通关屏从同一次捕获生成 `JournalReadingState.persistent()`，写入 `JournalUiPreferencesStore`；持久投影剔除批选。新建 Screen 与同世界重连可恢复最后表、Tab、各页号、tag、日志详情和条件偏移。目录展开、目录滚动和分类选择继续只在当前连接记忆；显式物品搜索使用其请求的内容上下文。

恢复先选择有效表并准备内容，再校验 tag、日志 entry 与详情模式，随后应用并钳制页号和 offset，最后恢复 Tab、过滤批选并更新 chrome。切表重置右页内容身份和页号；同表刷新先捕获后恢复。失效表或被当前投影过滤的表清除旧右页上下文，日志条目删除时回到列表并清除详情页号。

Screen 在目录与进度尚未完整提交时保留一次待恢复目标。客户端数据所有者的就绪状态和 revision 一同驱动既有刷新点，覆盖首次 revision 与初始值相同的情形；空目录也属于已就绪。恢复受连接 epoch 限定，新导航、键盘或搜索输入取消旧目标。过早关屏保存待恢复目标，避免将尚未加载的默认页覆盖到偏好。待恢复目标提交后若改变目录首页/列表模式，根 Screen 会按最终模式重建控件树，使工具栏几何、分类返回入口和内容投影保持一致；模式未改变时只同步动态控件状态。

本地文件按世界和玩家隔离：

- `journal_ui_preferences.dat` 由偏好 store 管理阅读投影、排序、搜索、收藏和模拟偏好；格式与连续迁移见[本地持久化](../foundation/persistence.md#21-客户端笔记偏好)。
- `journal_log_state.dat` 由 `JournalMirror` 管理会话、序号与本地日志镜像，沿既有冷却与整批快照协议工作。

`JournalLocalPersistence` 使用同目录临时文件和原子替换，保存失败保留待写冻结 NBT，由既有 tick/退出路径重试；同路径重连优先加载待写快照。切连接先保存旧路径，再推进 epoch 并复位。偏好格式读取失败或未来版本被拒时报告原因，当前路径保持只读以保留原文件。

## 7. 文本配色与裁剪生命周期

- 文本语义配色遵循[文本格式规范](../foundation/text-format.md)的「GUI 内文本规范」：Tooltip 使用 `TooltipBuilder`，书页自绘文本取 `UiTextScheme.PARCHMENT` 配合 `JournalTextColors`，管理/暗色页面取 `UiTextScheme.DARK`。
- 目录列表使用 `UiRenderLayers` 按当前 pose 换算裁剪，在绘制结束或异常退出时恢复父级裁剪。日志战利品的只读布局直接读取实际悬停槽位，以条目和物品签名提供稳定身份。
- 节点与文档缓存仅随内容版本、字体、资源或视口变化刷新，不在每帧重建树结构；3D 物品与模型在 `UiRenderLayers` 局部裁剪上下文内绘制，关屏时按作用域自动释放模型工作区。
