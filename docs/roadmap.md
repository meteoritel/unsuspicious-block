# 后续内容路线图

本文档记录 Unsuspicious Block 后续更新的内容计划与决策共识，供开发排期参考。随版本推进持续更新，已完成条目在表中标注状态，发布后整表移入「已发布」章节。

## 1. 总体策略

| 维度 | 决策 |
|---|---|
| 版本锚定 | 长期停留在 1.21.1（Fabric / NeoForge 双平台），不做新版本移植 |
| 发布节奏 | 小步快发，功能分批随 minor 版本发布，避免长周期主题大版本 |
| 目标玩家 | 收集 / 完成型玩家为主，休闲探索者为辅 |
| 开发约束 | 单人开发，工作量优先级高于内容完美度 |
| 设计驱动 | 以开发者自身体验痛点为主，结合社区反馈 |

## 2. 版本计划

### 2.1 1.5.2（近期第一批）

| 条目 | 内容 | 备注 |
|---|---|---|
| 标本箱图腾代理 | 标本箱放在背包（或饰品栏）中时，箱内的不死图腾即可生效 | **已实现（随 1.5.2 发布）**；与标本箱"代理装备效果"定位一致 |
| C 键联动 | 背包内或 JEI 物品列表上悬停物品按 `C`，以注册名在考古笔记执行一次搜索，命中则打开笔记并定位；考古笔记物品条目内支持 JEI 的 `U` / `R` 键查看用法与配方 | **已实现（随 1.5.2 发布）**；背包悬停部分不依赖 JEI；EMI 经 JEI 兼容层可受益，REI 暂不适配 |
| 统计总览页 | 总完成度、各来源（刷拭 / 钓鱼 / 开箱）次数、维度 / 群系分布等 | **部分实现（随 1.5.2 发布）**：首批落地首页右侧的刷拭 / 开箱累计次数、日志与标注数、最近记录与最近发现；总完成度、钓鱼来源、维度 / 群系分布视反馈后续补充 |
| 内容优化 | 不预设清单，随开发过程顺手改进 | — |

## 3. 冻结 / 排除项

以下内容本轮明确不做，避免开发资源分散：

| 条目 | 状态  | 说明 |
|---|-----|---|
| 猫族线全部内容 | 冻结  | 等猫猫 NPC 模型设计完成后重启。届时最高优先级为猫之手结构重新启用（结构自 1.4.1 起停用自然生成）；猫进度组为纯 JSON 不依赖模型，可随时低成本补上 |
| 掉落表目录扩展（怪物 / 方块掉落） | 长期候选 | 收集闭环的终极形态，但追踪范围、目录体积、性能均需重评估，本轮不纳入 |
| 嗅探兽生成可疑方块 | 不做  | — |
| 陶沙盘 | 不做  | — |
| 实体信息手册 / 容器内容预览 / 村民交易预览 | 不做  | 社区已有成熟模组，不重复造轮子 |
| 版本移植 | 暂不做 | 锚定 1.21.1 |
