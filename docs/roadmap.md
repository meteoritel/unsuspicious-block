# 产品规划

本页记录候选能力与资产目标。当前机制见[开发导航](dev/README.md)和[玩法规格](design/cat-bond.md)，具体执行和验收条件进入[实施计划](plan/README.md)。

## 产品方向

- Minecraft 1.21.1，Fabric / NeoForge 双平台；围绕考古探索、收集记录与猫族关系推进。
- 按可交付机制小步发布，优先解决实际使用问题。

## 候选能力

| 目标 | 实施前需要确定 |
|---|---|
| 考古生涯导出 | 导出内容、数据来源、隐私和复制格式 |
| 收集统计深化 | 总完成度、钓鱼及维度/群系维度的统计口径与保存方式 |
| 古园遗种附魔 | 锄草触发方式、奖励表、概率与获得途径 |
| 战利品目录扩展 | 新来源的追踪范围、收集闭环和模拟性能预算 |
| GUI 文本维护 | 按[文本格式](dev/foundation/text-format.md)核对 tooltip、语义色与本地化 |

## 猫族资产

结构自然生成当前停用，结构定义与模板保留。替换猫国结构及职业装饰时，先确定用户资产、生成分布和兼容要求，再制订实施与实机验收计划。信使服饰与灵体外观的当前实现见[实体与 AI](dev/subsystems/entities-world.md)。
