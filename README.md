# Unsuspicious Block

**Unsuspicious Block** 是一个围绕考古探索、战利品收集与发现记录展开的 Minecraft 模组。它为可疑方块带来扫描和快速发掘工具，并用一本会随探索逐渐完善的考古笔记，记录战利品、概率、发现地点与每次发掘经历。

## 模组能做什么

- **[考古笔记](https://github.com/meteoritel/unsuspicious-block/wiki/Archaeology-Journal)**：记录发现的战利品表、物品概率、坐标与发掘经历，并推进考古挑战进度。
- **[可疑解析仪与考古铲](https://github.com/meteoritel/unsuspicious-block/wiki/Reader-and-Shovel)**：扫描可疑方块直接查看内部战利品，再快速取出；范围扫描还能高亮附近的可疑方块与未开启的战利品容器。
- **[失落书页与附魔](https://github.com/meteoritel/unsuspicious-block/wiki/Lost-Pages-and-Enchantments)**：用考古发现的失落书页锻造附魔书，获得四种面向探索与收集的附魔。
- **[猫之瞳](https://github.com/meteoritel/unsuspicious-block/wiki/Eye-of-Cat)**：在附魔台、铁砧和砂轮中查看原本隐藏的完整信息。
- **[标本箱](https://github.com/meteoritel/unsuspicious-block/wiki/Specimen-Box)**：随身携带的 5 格容器，箱内部分物品可保持随身生效。
- **[纹饰陶轮台](https://github.com/meteoritel/unsuspicious-block/wiki/Pottery-Wheel)**：复制纹饰陶片、制作纹饰陶罐，并支持漏斗自动化。
- **[不可疑方块](https://github.com/meteoritel/unsuspicious-block/wiki/Unsuspicious-Blocks)**：把物品封存在伪装成可疑方块的沙子或沙砾中——拿去整蛊你的朋友。
