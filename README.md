# Unsuspicious Block

**Unsuspicious Block** 是一个面向 Minecraft `1.21.1` 的考古探索与发现记录模组。它为可疑方块提供扫描与快速发掘工具，并通过一本随探索不断完善的考古笔记，帮助你整理战利品来源、获取条件、估算概率与发掘坐标，同时拓展了淘洗、制陶、远古植物与遗迹重生成等玩法。

> English: [README_EN](README_EN.md)

![Unsuspicious Block 玩法概览](docs/image/readme/overview.png)

## 运行环境与依赖

| 项目 | 说明 |
|---|---|
| Minecraft | 1.21.1 |
| 当前基准版本 | 1.6.0 |
| 加载器 | Fabric 0.17.0+ / NeoForge 21.1.221+ |
| Java | 21 |
| 多人游戏 | 客户端与服务端均需安装 |

- **Fabric**：需要额外安装 [Fabric API](https://modrinth.com/mod/fabric-api)。
- **NeoForge**：无额外必需依赖。
- **界面依赖库**：模组使用 [Meteo's UI Kit](https://github.com/meteoritel/meteo-s-ui-kit)（`0.1.0-rc1`），发行版 JAR 已内嵌该库，玩家无需单独下载安装；源码构建与界面开发说明请见该仓库。
