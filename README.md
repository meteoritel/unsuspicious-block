# Unsuspicious Block

**Unsuspicious Block** is a Minecraft mod that enhances the archaeology system, allowing you to analyze and extract loot from suspicious blocks without the tedious brushing process.

## Features

### Three New Items

| Item                    | Description                                                                                                |
|-------------------------|------------------------------------------------------------------------------------------------------------|
| **Suspicious Reader**   | Right-click a suspicious block to reveal what's hidden inside — no brushing required!                      |
| **Luoyang Spade**       | A specialized excavation tool. Faster and more durable than a regular brush.                               |
| **Archaeology Journal** | A personal logbook that records every suspicious block you've brushed and every treasure you've unearthed. |

### Key Mechanics

- **Pre-excavation Scanning** — Use the Suspicious Reader on any suspicious sand or gravel to identify the hidden loot before you commit to brushing.
- **Faster Excavation** — The Luoyang Spade digs out items significantly faster than the vanilla brush.
- **Excavation History** — The Archaeology Journal automatically tracks your brushing history. Open it anytime to review what you've found and where.

### Optional Integrations

- **[Jade](https://modrinth.com/mod/jade)** — Displays Suspicious Reader results directly in the Jade HUD overlay.
